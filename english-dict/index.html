무료 도구 상태

    이 버전은 API 키 없이 무료 도구만 씁니다. 영영 뜻·발음 녹음은 Free Dictionary, 어원·영한 뜻은 위키낱말사전(Wiktionary), 번역은 Chrome 내장 번역기(없으면 MyMemory), 사진 글자 인식은 Tesseract를 써요.

    사용법
    1. 원서를 읽고 모르는 단어를 문맥으로 먼저 유추해 봅니다.
    2. [1 문장 입력]에 문장을 쓰거나 책 사진을 넣고 확정합니다.
    3. 모르는 단어를 클릭(구는 드래그)하고, 오른쪽에 유추한 뜻과 유추 사유를 적습니다.
    4. 사전 찾기를 누르면 [2 단어 해설]에 영영 · 영한 · 어원 · 문장 해석이 나와요. 영영사전에서 이 문장에 맞는 뜻을 고르고, 내 유추가 맞았는지 직접 판정하세요.
    5. [3 발음 교정]에서 원어민 음성을 듣고, 녹음해서 어디가 다르게 들리는지 확인하세요.

    단축키: Alt+1~5 화면 전환 · Ctrl+Enter 채점 · Alt+R 녹음 · Alt+L 듣기 · Esc 멈춤

    발음 인식은 Chrome / Edge 의 음성 인식을 씁니다. 처음 녹음할 때 마이크 권한을 허용해 주세요.
