## 1. 개요

### 1.1 배경
향장 향료(화장품·퍼스널케어 제품용 향료) 분야 조향사로서 경력, 전문 분야, 작업 방식을 한곳에 정리해 보여 줄 개인 프로필 사이트가 필요하다. 이력서나 명함만으로는 전하기 어려운 **향을 만드는 방식(크리에이션)**과 **제품에 적용하는 역량(어플리케이션)**을 글과 시각 자료로 보여 주는 것이 목적이다.

### 1.2 목표
- 처음 들어온 사람이 10초 안에 "누구이고 무엇을 하는 사람인지" 알 수 있다.
- 주 업무인 **향료 크리에이션**과 **어플리케이션** 역량이 분명하게 드러난다.
- 관심 있는 사람이 바로 이메일로 연락할 수 있다.
- 서버 없이 정적 파일만으로 동작하고, 무료 정적 호스팅에 올릴 수 있다.

### 1.3 비목표 (Out of Scope, v1)
- 블로그·게시판, 댓글, 회원 기능
- 관리자 페이지(CMS) — 내용은 파일을 직접 고쳐서 바꾼다
- 온라인 판매, 샘플 신청 결제
- 다국어 (v1은 한국어. 영어는 §10에서 결정)

## 4. 기능 요구사항

### 4.1 히어로 (첫 화면)
- 이름, 직함(예: `Perfumer · 향장 향료 크리에이션 & 어플리케이션`), 한 줄 소개.
- 버튼 두 개: `연락하기`(연락 섹션으로 이동), `작업 보기`(전문 분야로 이동).

### 4.2 소개 (About)
- 3~5문장 자기소개: 조향을 시작한 계기, 향을 대하는 관점.
- 선택: 프로필 사진 또는 일러스트.

### 4.3 전문 분야 (Expertise) — 핵심 섹션
주 업무 두 가지를 카드 두 장으로 나란히 보여 준다.

| 카드 | 담을 내용 (예시) |
|---|---|
| **향료 크리에이션** | 브리프 해석 → 콘셉트·무드 설정 → 처방 설계 → 수정·평가 반복. 주로 다루는 향 계열(플로럴, 시트러스, 머스크, 우디 등). |
| **어플리케이션** | 제형별 적용 평가(스킨케어, 바디·헤어, 세정 제품 등), 안정성·변색·발향 확인, 제형에 맞춘 처방 조정, 사용 농도 제안. |

- 그 아래 **제품군 태그**(샴푸, 바디워시, 로션, 크림, 핸드크림, 섬유유연제 등)와 **향 계열 태그**를 칩으로 나열한다.
- 선택: 작업 과정을 4단계 흐름도(브리프 → 크리에이션 → 어플리케이션 평가 → 최종 제안)로 그린다.

### 4.4 포트폴리오 (Works) — P1
- 대표 작업 3~6건을 카드로 보여 준다: 제품군, 향 계열, 콘셉트 한 줄, 맡은 역할.
- **고객사명·제품명·처방은 공개하지 않는 것이 기본**이다(기밀). 카드에는 "OO 브랜드 바디워시" 수준으로만 적는다.
- 카드를 누르면 콘셉트, 향 구성(탑·미들·베이스 노트), 어플리케이션에서 해결한 과제를 펼쳐 보여 준다.

### 4.5 경력 (Experience)
- 경력·학력·자격·교육을 세로 타임라인으로 보여 준다(최신이 위).
- 항목: 기간, 소속, 직무, 주요 업무 1~3줄.

### 4.6 연락 (Contact)
- 이메일 `sanho5785@naver.com`을 크게 보여 준다.
- `메일 보내기`(mailto 링크) / `주소 복사` 버튼. 복사하면 "복사했어요" 토스트를 띄운다.
- 스팸 수집을 줄이려고 HTML 원문에는 주소를 나눠 두고 스크립트로 조립한다(§8.3).
- 선택: LinkedIn 등 외부 링크.

### 4.7 공통
- 상단 고정 내비게이션: 소개 / 전문 분야 / 작업 / 경력 / 연락. 누르면 부드럽게 스크롤하고, 지금 보고 있는 섹션을 표시한다.
- 섹션이 화면에 들어올 때 은은하게 나타나는 효과. `prefers-reduced-motion` 설정이면 끈다.

## 6. 화면 설계

한 페이지 스크롤 구조.

```
┌─────────────────────────────────────────┐
│ 이름            소개 전문분야 작업 경력 연락 │  ← 고정 내비
├─────────────────────────────────────────┤
│                                         │
│   이름                                   │
│   Perfumer · 크리에이션 & 어플리케이션      │  ← 히어로
│   한 줄 소개                              │
│   [연락하기] [작업 보기]                   │
│                                         │
├─────────────────────────────────────────┤
│ 소개    사진 | 자기소개 문단               │
├─────────────────────────────────────────┤
│ 전문 분야                                 │
│ ┌─ 크리에이션 ─┐  ┌─ 어플리케이션 ─┐       │
│ └─────────────┘  └──────────────┘       │
│ #샴푸 #바디워시 #로션 …  #플로럴 #머스크 …  │
├─────────────────────────────────────────┤
│ 작업    [카드] [카드] [카드]               │
├─────────────────────────────────────────┤
│ 경력    ● 2024–  소속 · 직무              │
│         ● 2020–  …                       │
├─────────────────────────────────────────┤
│ 연락    sanho5785@naver.com              │
│         [메일 보내기] [주소 복사]          │
└─────────────────────────────────────────┘
```

### 6.1 디자인 방향 (초안, §10에서 확정)
- 분위기: 깨끗하고 차분한 실험실 + 향의 감성. 여백을 넉넉히.
- 색: 아이보리 바탕, 짙은 먹색 글자, 포인트 색 하나(예: 앰버 또는 세이지 그린).
- 글꼴: 본문 Pretendard, 제목은 세리프(예: Noto Serif KR)로 우아함을 준다.
- 장식: 향 계열을 색 점이나 얇은 선 그림(꽃·잎·나무)으로 표현. 사진은 시향지, 비커, 원료 정도.

## 7. 콘텐츠 구조

내용은 `index.html`에 바로 쓰지 않고 `content.js` 한 파일에 모아, 문구를 고칠 때 이 파일만 열면 되게 한다.

```js
const PROFILE = {
  name: '', title: 'Perfumer', tagline: '',
  email: { user: 'sanho5785', domain: 'naver.com' },
  about: [''],
  expertise: {
    creation:    { summary: '', points: [] },
    application: { summary: '', points: [] },
  },
  productTags: [],      // ['샴푸', '바디워시', ...]
  familyTags: [],       // ['플로럴', '머스크', ...]
  works: [              // P1
    { category: '', family: '', concept: '', role: '', notes: { top: [], middle: [], base: [] }, challenge: '' },
  ],
  experience: [
    { period: '', org: '', role: '', points: [] },
  ],
  links: [],            // [{ label: 'LinkedIn', url: '' }]
};
```

## 8. 기술 설계

### 8.1 파일 구조
```
demoport/
  index.html     # 뼈대와 섹션 틀
  style.css
  content.js     # 프로필 내용 (§7)
  app.js         # content.js 를 읽어 섹션을 그림, 내비·복사·애니메이션
  assets/        # 사진, 아이콘, og 이미지
  prd.md
```

### 8.2 실행
```bash
python -m http.server 8125 --bind 127.0.0.1 --directory demoport
```

### 8.3 이메일 보호
- 원문에 `sanho5785@naver.com`을 그대로 쓰지 않고 `content.js`의 `user`·`domain`을 스크립트가 조립해 mailto와 표시 문구를 만든다.
- 스크립트가 꺼진 환경을 위해 `<noscript>`에는 `sanho5785 [at] naver.com` 형태로 보여 준다.

### 8.4 배포
- GitHub Pages 또는 Netlify 같은 무료 정적 호스팅(§10에서 결정).

## 11. 수용 기준 (Acceptance Criteria, MVP)

- [ ] 첫 화면에 이름·직함·한 줄 소개가 보인다.
- [ ] 전문 분야에 크리에이션과 어플리케이션 카드가 나란히(모바일에서는 위아래로) 보인다.
- [ ] 경력 타임라인이 최신순으로 보인다.
- [ ] `메일 보내기`를 누르면 받는 사람이 `sanho5785@naver.com`인 메일 창이 열린다.
- [ ] HTML 원문에서 이메일 주소가 그대로 검색되지 않는다.
- [ ] 360px 폭에서 가로 스크롤이 생기지 않는다.
- [ ] 내비게이션 링크를 누르면 해당 섹션으로 이동하고 현재 섹션이 표시된다.
